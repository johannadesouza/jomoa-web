# Font Files

## The Seasons

Place The Seasons font files in this directory:

- `TheSeasons-Regular.woff2` (or `.woff`, `.ttf`)
- `TheSeasons-Italic.woff2` (or `.woff`, `.ttf`)

If you have different file names or formats, update the paths in `app/layout.tsx`.

## League Spartan

League Spartan is loaded from Google Fonts automatically - no files needed here.
