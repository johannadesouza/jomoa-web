# JOMOA Brand Colors Verification

All colors from Branding Guide Page 9:

## Primary Colors

- **softPink**: `#FFFBF7` - Main background
- **terracotta**: `#D96D46` - Primary CTA buttons
- **sand**: `#FEE7AB` - UI sections & accents (use with low opacity ~20%)
- **plum**: `#462324` - Headlines, strong text
- **mauve**: `#BA8E90` - Secondary buttons & accents

## Secondary Colors

- **pinkLight**: `#F0D6D7` - Light UI layers, borders
- **mauveDark**: `#976568` - Darker mauve variant
- **terracottaLight**: `#FDB499` - Lighter terracotta variant

## Usage in Tailwind

All colors are available as Tailwind classes:
- `bg-soft-pink`, `text-soft-pink`
- `bg-terracotta`, `text-terracotta`
- `bg-sand`, `text-sand`
- `bg-plum`, `text-plum`
- `bg-mauve`, `text-mauve`
- `bg-pink-light`, `text-pink-light`
- `bg-mauve-dark`, `text-mauve-dark`
- `bg-terracotta-light`, `text-terracotta-light`

## Typography

- **League Spartan**: Primary UI font (loaded from Google Fonts)
- **The Seasons**: Emotional slogans (needs font files in `public/fonts/`)
