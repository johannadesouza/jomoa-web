# Placeholder-features

Kort dokumentation av funktioner som är avsiktliga placeholders tills innehåll eller logik finns.

## Kost (Nutrition)

- **Status:** Fliken "Kost" i tab-navigatorn visar en placeholder-skärm med tomt state och länk till "Lär dig".
- **Beslut:** Behåll fliken och placeholder tills fasbaserade kosttips eller annat nutrition-innehåll är klart. Landningssidan har markerat graviditetsstöd som "kommer"; kost kan följa samma mönster vid behov.
- **Kod:** `src/features/nutrition/NutritionScreen.tsx`.
